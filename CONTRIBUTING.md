# Contributing

Thank you for improving this public demonstration. Keep all examples fictional and free of customer, employer, proprietary, export-controlled, or classified information.

Before opening a pull request:

1. Read the [writing guide](docs/contributing/writing-guide.md).
2. Run `python scripts/validate_docs.py`.
3. Run `zensical build --strict`.
4. Complete the [release checklist](docs/contributing/release-checklist.md).

Small, focused changes are easiest to review. Explain the reader problem, the content change, and the checks you performed.
