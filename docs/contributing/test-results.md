## What Is Tested

The workflow validates documentation structure, builds the production site, generates the Word and PDF handbooks, scans every maintained page with axe-core, and checks required responsive widths for horizontal overflow.

For scope, local commands, and limitations, see [Automated Accessibility and Regression Tests](automated-testing.md).
